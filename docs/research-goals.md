# Research Goals

LOOM investigates how much local AI capability can be extracted from constrained consumer hardware.

Primary questions:

1. What model size and architecture provide the best practical capability under severe memory constraints?
2. How much can quantization extend useful model size before quality loss outweighs gains?
3. How do MLX, llama.cpp and Ollama differ in memory pressure and throughput on Apple Silicon?
4. Can SSD-backed inference and MoE expert streaming make substantially larger models practically useful?
5. Can a fully local coding agent provide useful repository-level autonomy on an 8 GB machine?
6. Which metrics best distinguish “it runs” from “it is actually usable”?
